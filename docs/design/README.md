# Визуальная спецификация

`it-audit-concept.png` — утверждённый эталон двух основных состояний приложения.

## Дизайн-система

- Фон: настоящий белый `#FFFFFF`.
- Основной текст: тёмно-синий `#10182F`.
- Акцент: синий `#123FAD`.
- Риски: красный `#E53935`, предупреждение `#F59E0B`.
- Разделители: `#D9DEE8`; небольшие радиусы; минимальные тени.
- Контейнеры: открытые списки, таблицы, шкалы и временная линия; без bento-сетки.
- Шрифт: Arial/Helvetica, выразительные заголовки и компактный текст контролов.

## Разрешённый основной текст

«ИТ-Аудит», «Новый аудит», «История», «Профиль компании», «Шаг N из 5»,
названия полей и категорий, «Назад», «Продолжить», «Рассчитать»,
«Результаты аудита», «Ключевые риски», «План 30 / 60 / 90 дней»,
«Сохранить аудит», «Экспортировать отчёт».

## Иконки

Используются встроенные Material Symbols Streamlit: новый аудит, история,
стрелки навигации, сохранение, скачивание и добавление.

## Допустимое функциональное отклонение

Кнопка «Начать новый аудит» добавлена после результата, поскольку без неё
однопользовательский локальный сценарий нельзя повторить без перезапуска сессии.
