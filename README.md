# ИТ-Аудит

Локальное русскоязычное приложение для первичного аудита ИТ-зрелости компании.
Консультант заполняет 16 вопросов, получает оценки по четырём направлениям,
ключевые риски и план действий на 30, 60 и 90 дней.

## Возможности

- пятишаговая анкета с сохранением ответов при возврате назад;
- нормализованные оценки от 0 до 100;
- три приоритетных риска и детерминированные рекомендации;
- история завершённых аудитов в SQLite;
- автономный HTML-отчёт, который можно напечатать в PDF через браузер;
- адаптивный интерфейс для desktop и мобильного окна.

## Требования

- Python 3.14;
- Windows PowerShell, Terminal или совместимая оболочка;
- современный браузер.

## Установка и запуск

В PowerShell из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Приложение откроется на `http://localhost:8501`.

Если политика PowerShell запрещает активацию окружения, используйте команды без активации:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## Тесты и проверка кода

```powershell
python -m pip install -r requirements-dev.txt
pytest -q
```

## Данные

По умолчанию SQLite создаётся в `data/it_audit.db`. Файл базы не попадает в Git.
Путь можно изменить переменной окружения:

```powershell
$env:IT_AUDIT_DB_PATH = "D:\audit-data\it_audit.db"
python -m streamlit run app.py
```

Приложение рассчитано на одного пользователя. При локальном запуске авторизации нет;
VPS-конфигурация защищает весь сайт на уровне reverse proxy. Облачной синхронизации
и внешних API нет.

## Экспорт в PDF

Скачайте HTML кнопкой «Экспортировать отчёт», откройте файл в браузере и выберите
«Печать» → «Сохранить как PDF».

## Методика

Каждый вопрос оценивается от 1 до 5. Оценка направления рассчитывается как
`round((среднее − 1) / 4 × 100)`. Результат является демонстрационным инструментом
для первичного обсуждения и не заменяет полноценное обследование.

## Развёртывание на Ubuntu 22.04 VPS

VPS-вариант использует два контейнера:

- Streamlit доступен только внутри Docker-сети;
- Caddy публикует порты 80/443, включает Basic Auth и локальный HTTPS-сертификат;
- SQLite хранится на сервере в `/opt/it-audit/data` и переживает обновления контейнера.

В Git не записывается пароль или его открытое значение. Установщик запрашивает пароль
скрытым вводом и сохраняет в Caddy только bcrypt-хеш. Фиксированный логин — `audit`.

### 1. Собрать единый установочный файл

В Windows из чистой закоммиченной ветки:

```powershell
powershell -ExecutionPolicy Bypass -File deploy/build-bundle.ps1
```

Будет создан `dist/it-audit-installer.sh`. Загрузите только этот файл на VPS через
панель провайдера, SFTP или `scp` с парольной авторизацией. Доступ VPS к GitHub и SSH-ключи
для репозитория не нужны.

### 2. Выполнить на VPS одну команду

```bash
sudo bash ./it-audit-installer.sh
```

Установщик проверит Ubuntu 22.04, установит Docker Engine и Compose из официального
apt-репозитория, определит публичный IP, скрыто запросит пароль, соберёт контейнеры и
проверит healthcheck. При запросе пароля введите выбранный вами пароль дважды.

После установки:

```text
Адрес: https://IP_СЕРВЕРА
Логин: audit
Пароль: введённый при установке
```

Так как домена нет, используется локальный сертификат Caddy. Браузер покажет
предупреждение о недоверенном центре сертификации — убедитесь, что открыт правильный IP,
и разрешите переход. Соединение после этого остаётся зашифрованным.

В панели VPS или security group должны быть разрешены входящие TCP-порты 80 и 443.
Порт 8501 открывать не нужно. Не используйте этот демонстрационный вариант для особо
чувствительных данных без доверенного домена и сертификата.

### Обновление

Соберите свежий `it-audit-installer.sh`, загрузите его на VPS и снова выполните ту же
команду. Установщик обновит приложение в `/opt/it-audit`, но сохранит SQLite в каталоге
`/opt/it-audit/data`.

Полезные команды на VPS:

```bash
cd /opt/it-audit
sudo docker compose ps
sudo docker compose logs --tail=100
sudo docker compose restart
```
